# Risk & Reserve Model

## Purpose

Explore the economics of repair protection for rebuilt vehicles without conflating a reserve model with an insurance or warranty product.

## Starting Concept

A working scenario discussed for the platform is collecting approximately $3,000 per vehicle in premium-like revenue or reserve contribution to absorb future repair costs.

That number is not yet an actuarially validated premium. It is an input for scenario modelling.

## Core Variables

Expected annual claim cost per vehicle = claim frequency × average claim severity.

Required contribution should then consider:
- expected claims;
- administration;
- provider/claims handling costs;
- fraud/leakage;
- adverse selection;
- acquisition costs;
- taxes;
- required contingency margin;
- target reserve ratio;
- reinsurance or stop-loss, if applicable.

## Illustrative Framework

For a pool of N vehicles:

Expected Claims = N × Frequency × Average Severity

Required Reserve = Expected Claims + Expense Load + Risk Margin

Contribution per Vehicle = Required Reserve ÷ N

## Sensitivity Example

If 100 vehicles are enrolled and 20% have a covered repair averaging $4,000:

Expected claims = 100 × 20% × $4,000 = $80,000

Expected pure claim cost = $800 per vehicle.

A $3,000 contribution would create $300,000 gross funds before expenses, leaving substantial room in this simple scenario. But if claim frequency or severity rises materially, economics change quickly.

## Required Validation Before Launch

Before any self-funded program is marketed, obtain:
- actuarial review;
- BC legal/regulatory review;
- insurance/warranty classification review;
- tax/accounting treatment;
- claims administrator design;
- reserve governance;
- exclusions and contract wording;
- catastrophic loss protection;
- consumer disclosure review.

## MVP Decision

Use third-party warranty coverage first. Treat self-funded repair protection as a later research stream, not a core MVP dependency.
